.. py:function:: evaluate_cubic_at(poly: sympy.Expr, pt: BarycentricPoint) -> bool

   Return ``True`` iff ``poly`` vanishes identically at ``pt``.

   Reduces the algebraic extensions ``S^2 = S_A S_B + S_B S_C + S_C S_A`` and
   ``r3^2 = 3`` via exact polynomial division in SymPy.

   :param poly: Homogeneous cubic polynomial in ``(x, y, z)``.
   :param pt: Exact symbolic barycentric coordinates ``(u, v, w)``.

   :returns: ``True`` if ``poly(u, v, w) == 0`` identically over ``Q(a, b, c, S, sqrt(3))``.

.. py:function:: barycentric_to_cartesian(pt: BarycentricPoint, a_val: float, b_val: float, c_val: float, vertices: tuple[tuple[float, float], tuple[float, float], tuple[float, float]]) -> tuple[float, float] | None

   Convert symbolic barycentric coordinates to 2D Cartesian coordinates for SVG rendering.

   Returns ``None`` if the point lies at infinity (sum of coordinates is zero).

   :param pt: Symbolic barycentric triple ``(x, y, z)``.
   :param a_val: Numeric side length ``a = |BC|``.
   :param b_val: Numeric side length ``b = |CA|``.
   :param c_val: Numeric side length ``c = |AB|``.
   :param vertices: Cartesian coordinates ``(A, B, C)`` of the reference triangle.

   :returns: ``(X, Y)`` Cartesian coordinates, or ``None`` for points at infinity.
