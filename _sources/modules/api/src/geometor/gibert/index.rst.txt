.. py:function:: evaluate_cubic_at(poly: sympy.Expr, pt: BarycentricPoint) -> bool

   Return ``True`` iff ``poly`` vanishes identically at ``pt``.

   Reduces the algebraic extensions ``S^2 = S_A S_B + S_B S_C + S_C S_A`` and
   ``r3^2 = 3`` via exact polynomial division in SymPy.

   :param poly: Homogeneous cubic polynomial in ``(x, y, z)``.
   :param pt: Exact symbolic barycentric coordinates ``(u, v, w)``.

   :returns: ``True`` if ``poly(u, v, w) == 0`` identically over ``Q(a, b, c, S, sqrt(3))``.

.. py:function:: pk_isogonal(pivot: src.geometor.gibert.centers.BarycentricPoint) -> sympy.Expr

   Return the exact homogeneous barycentric polynomial for ``pK(X6, P)``.

   Defined as ``det(M, M*, P) = 0``, where ``M = (x : y : z)`` and
   ``M* = (a^2 y z : b^2 z x : c^2 x y)`` is the isogonal conjugate of ``M``.

   :param pivot: Exact barycentric coordinates ``(u, v, w)`` of the pivot ``P``.

   :returns: Expanded homogeneous cubic polynomial in ``(x, y, z)``.


.. py:function:: pk_isotomic(pivot: src.geometor.gibert.centers.BarycentricPoint) -> sympy.Expr

   Return the exact homogeneous barycentric polynomial for ``pK(X2, P)``.

   Defined as ``det(M, M^tau, P) = 0``, where ``M = (x : y : z)`` and
   ``M^tau = (y z : z x : x y)`` is the isotomic conjugate of ``M``.

   :param pivot: Exact barycentric coordinates ``(u, v, w)`` of the pivot ``P``.

   :returns: Expanded homogeneous cubic polynomial in ``(x, y, z)``.
