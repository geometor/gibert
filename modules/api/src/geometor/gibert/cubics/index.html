src.geometor.gibert.cubics.pk_isogonal(pivot: src.geometor.gibert.centers.BarycentricPoint) → sympy.Expr¶

Return the exact homogeneous barycentric polynomial for pK(X6, P).

Defined as det(M, M*, P) = 0, where M = (x : y : z) and M* = (a^2 y z : b^2 z x : c^2 x y) is the isogonal conjugate of M.

Parameters:

pivot – Exact barycentric coordinates (u, v, w) of the pivot P.

Returns:

Expanded homogeneous cubic polynomial in (x, y, z).

src.geometor.gibert.cubics.pk_isotomic(pivot: src.geometor.gibert.centers.BarycentricPoint) → sympy.Expr¶

Return the exact homogeneous barycentric polynomial for pK(X2, P).

Defined as det(M, M^tau, P) = 0, where M = (x : y : z) and M^tau = (y z : z x : x y) is the isotomic conjugate of M.

Parameters:

pivot – Exact barycentric coordinates (u, v, w) of the pivot P.

Returns:

Expanded homogeneous cubic polynomial in (x, y, z).

src.geometor.gibert.cubics.lemoine_cubic_polynomial() → sympy.Expr¶

Return the exact homogeneous barycentric polynomial for K009 (Lemoine cubic).

Locus of M = (x : y : z) whose cevians MA, MB, MC meet the perpendicular bisectors of BC, CA, AB in three collinear points.

src.geometor.gibert.cubics.simson_cubic_polynomial() → sympy.Expr¶

Return the exact homogeneous barycentric polynomial for K010 (Simson cubic).

Locus of the tripoles (trilinear poles) of the Simson lines of ABC.

src.geometor.gibert.cubics.tucker_cubic_polynomial() → sympy.Expr¶

Return the exact homogeneous barycentric polynomial for K011 (Original Tucker cubic).

Locus of M = (x : y : z) whose cevian triangle has the same signed area as the orthic triangle of ABC.
