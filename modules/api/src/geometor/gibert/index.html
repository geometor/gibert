src.geometor.gibert.evaluate_cubic_at(poly: sympy.Expr, pt: BarycentricPoint) → bool¶

Return True iff poly vanishes identically at pt.

Reduces the algebraic extensions S^2 = S_A S_B + S_B S_C + S_C S_A and r3^2 = 3 via exact polynomial division in SymPy.

Parameters:

  • poly – Homogeneous cubic polynomial in (x, y, z).

  • pt – Exact symbolic barycentric coordinates (u, v, w).

Returns:

True if poly(u, v, w) == 0 identically over Q(a, b, c, S, sqrt(3)).

src.geometor.gibert.pk_isogonal(pivot: src.geometor.gibert.centers.BarycentricPoint) → sympy.Expr¶

Return the exact homogeneous barycentric polynomial for pK(X6, P).

Defined as det(M, M*, P) = 0, where M = (x : y : z) and M* = (a^2 y z : b^2 z x : c^2 x y) is the isogonal conjugate of M.

Parameters:

pivot – Exact barycentric coordinates (u, v, w) of the pivot P.

Returns:

Expanded homogeneous cubic polynomial in (x, y, z).

src.geometor.gibert.pk_isotomic(pivot: src.geometor.gibert.centers.BarycentricPoint) → sympy.Expr¶

Return the exact homogeneous barycentric polynomial for pK(X2, P).

Defined as det(M, M^tau, P) = 0, where M = (x : y : z) and M^tau = (y z : z x : x y) is the isotomic conjugate of M.

Parameters:

pivot – Exact barycentric coordinates (u, v, w) of the pivot P.

Returns:

Expanded homogeneous cubic polynomial in (x, y, z).
